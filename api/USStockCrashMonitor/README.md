## 📖 项目简介 (Introduction)

在金融市场中，单一指标往往具有欺骗性。本项目旨在构建一个**多因子风险加权模型**，通过整合华尔街最受关注的宏观估值指标（如巴菲特指标、席勒市盈率）与技术面指标（如均线乖离率、美债收益率曲线），计算出一个综合的 **"崩盘风险评分 (Crash Risk Score)"**。

该工具帮助投资者在市场极度狂热时保持冷静，在极度恐慌时寻找机会，拒绝做"韭菜"。

## 🆕 v1.3 更新日志 (What's New)

**本版本核心：风险模型从"线性加权"升级为"六因子 + 非线性 + 共振检测"，更贴近崩盘的真实特征。**

* 🧠 **新增第6因子「信用利差 (高收益债 HY OAS)」**：与股市自身指标（估值/情绪/技术）**零重叠**的正交信号。信用市场由机构定价，是"聪明钱"，2008/2020 崩盘前常领先股市 1-2 个月扩大。数据来自 FRED `BAMLH0A0HYM2`（需免费 key）。
* 📊 **分位数化评分**：有历史序列的因子（信用利差等）改用**5年滚动历史分位数**，自动适应利率/估值环境变化，解决静态阈值失真问题。
* 📈 **非线性放大**：对极端读数做幂变换，让"极端"贡献非线性增长（更贴近崩盘的非线性本质）。
* 🔴 **共振警报**：当 ≥3 个因子同时进入历史极端区时，触发红色警报并额外加分——多指标同时爆表才是崩盘的典型前兆。
* 🚩 **最大单项红线托底**：防止某个极端因子被其他温和因子稀释（如 2008 雷曼时信用利差爆表但其他因子温和），单因子爆表时总分自动托底。
* 🧩 **新增「因子贡献度」图**：直观展示每个因子实际贡献了多少风险分，一眼看出当前主要风险来源。
* 📉 **新增「风险评分趋势」图**：每次运行自动累积当日评分到本地，绘制风险随时间的演变曲线——把"快照"升级为真正的"监测仪"。
* 📈 **K线图增强**：新增成交量副图 + 50日均线，红涨绿跌配色。
* 🧹 **代码重构**：评分逻辑抽离为独立 `risk_model.py`；消除行情数据重复下载；清理冗余依赖与死代码。

> ⚠️ **权重说明**：v1.3 采用六因子，权重**自动归一化**（无需手动凑满 100%）。历史基准 (2000/2008/2022) 已用新模型重算：2000峰=70 / 2008前=46 / 2022峰=63。

## ✨ 核心功能 (Features)

* **多维度量化模型**：结合**宏观经济 (Macro)**、**估值 (Valuation)**、**市场情绪 (Sentiment)** 和 **技术形态 (Technical)** 的综合评分系统。
* **双标的切换**：支持 **VOO (S&P 500)** 和 **QQQ (Nasdaq 100)** 自由切换，针对不同波动率的资产独立分析。
* **数据全自动化**：7 大指标自动获取，无需手动查数；网络异常自动降级，国内网络环境已适配。
* **高度可定制化**：
  * **权重调节**：根据当前市场环境（如高息环境或AI泡沫）动态调整各指标权重。
  * **手动校准**：每个指标均可一键切换为手动输入，灵活覆盖。
* **历史数据对比**：提供 2000年、2008年、2022年等历史关键崩盘点的阈值参考与跨时代风险打分对比。
* **交互式图表**：Plotly 绘制的高性能交互式 K 线图与风险仪表盘。

## 🛠️ 监测指标体系 (Indicators)

本模型基于以下 6 大核心因子计算风险（v1.3，权重可调且自动归一化）：

1. **巴菲特指标 (Buffett Indicator)**：美股总市值 / 美国 GDP。衡量整体股市泡沫程度。
2. **席勒市盈率 (Shiller PE / CAPE)**：经通胀调整的周期性市盈率，穿越牛熊的估值标尺。
3. **高收益债信用利差 (HY OAS)** 🆕：与股市指标正交的"聪明钱"信号。信用市场由机构定价，崩盘前常领先股市 1-2 个月扩大。采用 5 年历史分位数评分。
4. **美债收益率曲线 (10Y-2Y Spread)**：著名的衰退预警指标，重点监测"倒挂后解挂"的高危时刻。
5. **200日均线乖离率 (200-MA Deviation)**：衡量价格短期偏离长期趋势的程度，判断是否严重超买。
6. **恐慌与贪婪指数 (Fear & Greed Index)**：反向指标，极度贪婪往往预示着短期顶部（该指数已内含 VIX/Put-Call/动量等子指标，故不重复叠加）。

**评分机制 (v1.3)**：六因子分位数化 + 非线性放大 + **共振警报**（多因子同时极端时加分）+ **最大单项红线托底**（防止极端信号被稀释）。比 v1.2 的纯线性加权更贴近崩盘的非线性特征。

## 🚀 快速开始 (Installation & Usage)

### 环境要求

* Python 3.8 或更高版本

### 安装步骤

**1. 克隆仓库**
```bash
git clone https://github.com/middletoo/US_Stock_Crash_Monitor.git
cd US_Stock_Crash_Monitor
```

**2. 安装依赖**
```bash
pip install -r requirements.txt
```

**3. (可选但推荐) 配置 FRED API key 实现全自动化**

巴菲特指标与美国 GDP 走 FRED 官方数据，需一个免费 key：

* 30秒免费申请： https://fred.stlouisfed.org/docs/api/api_key.html
* 复制 `.env.example` 为 `.env`，填入你的 key：
  ```
  FRED_API_KEY=你的key
  ```
* **不配置也能用**：巴菲特指标自动改用 GuruFocus 抓取兜底，仅 GDP 需手动。

**4. 运行应用**
```bash
streamlit run app.py
```

**5. 访问应用**

浏览器自动打开 http://localhost:8501

### 使用方法

1. **开箱即用**：启动后所有指标自动获取实时数据，顶部显示数据源状态（🟢 全绿即全部自动成功）。
2. **刷新数据**：数据默认缓存 30 分钟，点侧边栏"♻️ 刷新所有数据"强制更新。
3. **调整权重**：展开"⚖️ 模型权重配置"，按当前市场环境拖动滑块（v1.3 起自动归一化，无需凑满 100%）。
4. **手动校准**：任一指标勾选"✏️ 手动校准此指标"即可覆盖自动值（例如你信赖的其他数据源）。
5. **网络异常**：若 Yahoo Finance 连接失败，在"🌐 网络连接设置"填入代理，或留空自动进入模拟演示模式。
6. **切换标的**：侧边栏顶部选择 VOO (标普500) 或 QQQ (纳指100)。

## ⚠️ 局限性与缺点 (Limitations)

* **数据滞后性**：GDP 为季度更新，巴菲特指标无法反映实时日内变化，适合看长期趋势，不适合短线择时。
* **模型非线性仍有限**：v1.3 已引入分位数化、共振警报与红线托底，但本质仍是规则化评分（非机器学习），无法预测"黑天鹅"的精确时点——它衡量的是"脆弱性"，不是"引爆时间"。
* **历史分位数依赖**：信用利差等因子的分位数评分依赖历史序列长度，在数据窗口较短时（如序列仅覆盖近3年）分位参考意义会打折扣。
* **网页抓取脆弱性**：Shiller PE / 巴菲特指标 / 恐慌指数依赖第三方网页或私有 API 抓取，若目标站点改版可能导致解析失败（已内置降级与手动覆盖兜底）。
* **主观因素**：虽然数据已自动化，但权重设置与各因子阈值仍包含一定的主观判断。
